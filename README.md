# Challenge Yourself — free iPhone-friendly web app

No Mac, App Store account, paid API, login, or backend required. This is a Progressive Web App (PWA), designed for iPhone Safari. Publish it free with GitHub Pages, then add it to your Home Screen.

## Included
- Create personal challenges by typing, plus optional speech-to-text where supported by the browser.
- Easy and Medium have 24 hours; Difficult has 48 hours.
- Expired challenges can be manually restarted for a fresh full timer.
- Rewards stay locked until you mark a challenge complete.
- History and unlocked rewards tabs, dark mobile layout, local storage, basic offline cache.


## Add to iPhone
1. Open the published HTTPS URL in **Safari**.
2. Tap Share → **Add to Home Screen**.
3. Name it and tap **Add**.

## Notes
- This is a web app, not an App Store-published native app.
- Challenges are saved only in that browser on that device. Clearing Safari website data can erase them; there is no cross-device sync.
- iOS Safari speech recognition support can vary. If the microphone feature is unavailable, type the challenge instead.
- Timers use the device clock; enable automatic date and time on your iPhone.
